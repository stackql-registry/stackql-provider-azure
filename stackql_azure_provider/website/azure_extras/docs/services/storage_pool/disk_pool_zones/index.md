Lists available Disk Pool Skus in an Azure location.

```sql
SELECT
additionalCapabilities,
availabilityZones,
sku
FROM azure_extras.storage_pool.disk_pool_zones
WHERE location = '{{ location }}' -- required
AND subscription_id = '{{ subscription_id }}' -- required
;
```
