## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Returns a cloud specific manifest JSON file.

```sql
SELECT
id,
name,
deploymentData,
etag,
signature,
type
FROM azure_stack.azurestack.cloud_manifest_file
WHERE verification_version = '{{ verification_version }}' -- required
AND versionCreationDate = '{{ versionCreationDate }}'
;
```
</TabItem>
<TabItem value="list">

Returns a cloud specific manifest JSON file with latest version.

```sql
SELECT
id,
name,
deploymentData,
etag,
signature,
type
FROM azure_stack.azurestack.cloud_manifest_file
;
```
</TabItem>
