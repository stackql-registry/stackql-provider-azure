## `SELECT` examples

    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },

    ]}
>
<TabItem value="get">

Get a platform update.

```sql
SELECT
id,
name,
platformUpdateDetails,
systemData,
type
FROM azure_stack.azure_stack_hci.platform_updates
WHERE location = '{{ location }}' -- required
AND platform_update_name = '{{ platform_update_name }}' -- required
AND subscription_id = '{{ subscription_id }}' -- required
;
```
</TabItem>
<TabItem value="list">

List all platform updates.

```sql
SELECT

FROM azure_stack.azure_stack_hci.platform_updates

AND subscription_id = '{{ subscription_id }}' -- required
;
```
