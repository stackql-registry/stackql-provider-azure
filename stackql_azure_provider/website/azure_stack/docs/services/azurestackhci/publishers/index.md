## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },

    ]}

<TabItem value="get">

Get Publisher resource details of HCI Cluster.

```sql
SELECT
id,
name,
provisioningState,
systemData,
type
FROM azure_stack.azurestackhci.publishers
WHERE resource_group_name = '{{ resource_group_name }}' -- required
AND cluster_name = '{{ cluster_name }}' -- required
AND publisher_name = '{{ publisher_name }}' -- required
AND subscription_id = '{{ subscription_id }}' -- required
;
```
</TabItem>
<TabItem value="list_by_cluster">

List Publishers available for the HCI Cluster.

```sql
SELECT
id,
name,
provisioningState,
systemData,
type
FROM azure_stack.azurestackhci.publishers
WHERE resource_group_name = '{{ resource_group_name }}' -- required
AND cluster_name = '{{ cluster_name }}' -- required
AND subscription_id = '{{ subscription_id }}' -- required
;
```
