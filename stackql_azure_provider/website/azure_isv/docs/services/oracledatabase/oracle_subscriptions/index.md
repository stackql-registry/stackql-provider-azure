Get a OracleSubscription.

```sql
SELECT
id,
name,
addSubscriptionOperationState,
azureSubscriptionIds,
cloudAccountId,
cloudAccountState,
intent,
lastOperationStatusDetail,
plan,
productCode,
provisioningState,
saasSubscriptionId,
systemData,
termUnit,
type
FROM azure_isv.oracledatabase.oracle_subscriptions
WHERE subscription_id = '{{ subscription_id }}' -- required
;
```
