## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' }
    ]}
>
<TabItem value="get">

Gets information about a migration in a Redis Enterprise cluster.

```sql
SELECT
id,
name,
creationTime,
lastModifiedTime,
provisioningState,
sourceType,
statusDetails,
systemData,
targetResourceId,
type
FROM azure_isv.redisenterprise.migration
WHERE resource_group_name = '{{ resource_group_name }}' -- required
AND cluster_name = '{{ cluster_name }}' -- required
AND subscription_id = '{{ subscription_id }}' -- required
;
```
</TabItem>
</Tabs>

```sql

@resource_group_name='{{ resource_group_name }}' --required, 
@cluster_name='{{ cluster_name }}' --required,

'{
"properties": "{{ properties }}"
}'
;
```
</TabItem>
<TabItem value="cancel">

Cancel or rollback the migration operation in a Redis Enterprise cluster.

```sql
EXEC azure_isv.redisenterprise.migration.cancel 
@resource_group_name='{{ resource_group_name }}' --required, 
@cluster_name='{{ cluster_name }}' --required, 
@subscription_id='{{ subscription_id }}' --required
;
```

</TabItem>
