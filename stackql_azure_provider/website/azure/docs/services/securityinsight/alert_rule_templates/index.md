## `SELECT` examples

    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },

>
<TabItem value="get">

Gets the alert rule template.

```sql
SELECT
id,
name,
kind,
systemData,
type
FROM azure.securityinsight.alert_rule_templates
WHERE resource_group_name = '{{ resource_group_name }}' -- required
AND workspace_name = '{{ workspace_name }}' -- required
AND alert_rule_template_id = '{{ alert_rule_template_id }}' -- required
AND subscription_id = '{{ subscription_id }}' -- required
;
```
</TabItem>
<TabItem value="list">

Gets all alert rule templates.

```sql
AND subscription_id = '{{ subscription_id }}' -- required
;
```
