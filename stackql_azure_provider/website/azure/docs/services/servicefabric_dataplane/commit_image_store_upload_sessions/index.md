Commit an image store upload session. When all file chunks have been uploaded, the upload session needs to be committed explicitly to complete the upload. Image store preserves the upload session until the expiration time, which is 30 minutes after the last chunk received. .

```sql
EXEC azure.servicefabric_dataplane.commit_image_store_upload_sessions.commit_image_store_upload_session 
@session-id='{{ session-id }}' --required, 
@endpoint='{{ endpoint }}' --required, 
@timeout='{{ timeout }}'
;
```
