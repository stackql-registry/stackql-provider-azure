Gets all the available express route service providers.

```sql
SELECT
id,
name,
bandwidthsOffered,
location,
peeringLocations,
provisioningState,
tags,
type
FROM azure.network.express_route_service_providers
WHERE subscription_id = '{{ subscription_id }}' -- required
;
```
