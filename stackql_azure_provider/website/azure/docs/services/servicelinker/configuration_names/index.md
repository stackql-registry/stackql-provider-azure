Lists the configuration names generated by Service Connector for all target, client types, auth types.

```sql
SELECT
authType,
clientType,
daprProperties,
names,
secretType,
targetService
FROM azure.servicelinker.configuration_names
WHERE $filter = '{{ $filter }}'
AND $skipToken = '{{ $skipToken }}'
;
```
