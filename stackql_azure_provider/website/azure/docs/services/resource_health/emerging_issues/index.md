## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Gets Azure services' emerging issues.

```sql
SELECT
id,
name,
refreshTimestamp,
statusActiveEvents,
statusBanners,
systemData,
type
FROM azure.resource_health.emerging_issues
WHERE issue_name = '{{ issue_name }}' -- required
;
```
</TabItem>
<TabItem value="list">

Lists Azure services' emerging issues.

```sql
SELECT
id,
name,
refreshTimestamp,
statusActiveEvents,
statusBanners,
systemData,
type
FROM azure.resource_health.emerging_issues
;
```
