## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Gets the details of the policy.

```sql
SELECT
id,
name,
customProperties,
provisioningState,
systemData,
type
FROM azure.recovery_services_data_replication.policy
WHERE resource_group_name = '{{ resource_group_name }}' -- required
AND vault_name = '{{ vault_name }}' -- required
AND policy_name = '{{ policy_name }}' -- required
AND subscription_id = '{{ subscription_id }}' -- required
;
```
</TabItem>
<TabItem value="list">

Gets the list of policies in the given vault.

```sql

id,

;
```
</TabItem>
</Tabs>
