Lists all available managed rule sets.

```sql
SELECT
id,
name,
provisioningState,
ruleGroups,
ruleSetType,
ruleSetVersion,
sku,
systemData,
type
FROM azure.cdn.managed_rule_sets
WHERE subscription_id = '{{ subscription_id }}' -- required
;
```
