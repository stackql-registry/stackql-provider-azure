<Tabs
    defaultValue="get"

<TabItem value="get">

Get the properties of a specific dashboard for grafana resource.

```sql
SELECT
id,
name,
location,
provisioningState,
systemData,
tags,
type
FROM azure.dashboard.managed_dashboards
WHERE resource_group_name = '{{ resource_group_name }}' -- required
AND dashboard_name = '{{ dashboard_name }}' -- required
AND subscription_id = '{{ subscription_id }}' -- required
;
```
</TabItem>
<TabItem value="list">

List all resources of dashboards under the specified resource group.


</TabItem>

<TabItem value="create">

Create or update a dashboard for grafana resource. This API is idempotent, so user can either create a new dashboard or update an existing dashboard.

```sql
INSERT INTO azure.dashboard.managed_dashboards (
tags,
location,
properties,
resource_group_name,
dashboard_name,
subscription_id
)
SELECT 
'{{ tags }}',
'{{ location }}' /* required */,
'{{ properties }}',
'{{ resource_group_name }}',
'{{ dashboard_name }}',
'{{ subscription_id }}'
RETURNING
id,
name,
location,
properties,
systemData,
tags,
type
;
```
</TabItem>
