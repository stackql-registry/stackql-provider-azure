## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Get a specific custom recommendation for the requested scope by customRecommendationName.

```sql
SELECT
id,
name,
assessmentKey,
cloudProviders,
description,
displayName,
query,
remediationDescription,
securityIssue,
severity,
systemData,
type
FROM azure.security.custom_recommendations
WHERE scope = '{{ scope }}' -- required
AND custom_recommendation_name = '{{ custom_recommendation_name }}' -- required
;
```
</TabItem>
<TabItem value="list">

Get a list of all relevant custom recommendations over a scope.

```sql

```
